# Платіжний шлюз RozetkaPay Оплата частинами для WooCommerce 

<p align="center">
  <img src="assets/images/rozetkapay-logo.png" alt="Логотип RozetkaPay" width="200" />
</p>

WooCommerce Payment Gateway для оплати товарів банкывськими картами або оплатою частинами через RozetkaPay

---

## Опис

**RozetkaPay Payparts Gateway для WooCommerce** — цце платіжний шлюз, який дозволяє вашому магазину WooCommerce приймати оплату банківськими картами та оплату частинами через RozetkaPay.

- **Версія:** 2.0.3
- **Автор:** RozetkaPay
- **Вимагає PHP:** 7.4+
- **Вимагає WordPress:** 5.0+
- **Вимагає WooCommerce:** 5.0+
- **Протестовано з WordPress:** 6.8.3
- **Протестовано з WooCommerce:** 9.4.1

---

## Можливості

- Прийом платежів через RozetkaPay на сторінці оформлення замовлення WooCommerce
- Віджет «Оплата частинами» на сторінках товарів та в кошику:
  - розрахунок орієнтовного щомісячного платежу;
  - вибір кількості місяців;
  - підтримка кількох банків-партнерів (Monobank, izibank, А-Банк, ПриватБанк, RozetkaPay тощо).
- Додатковий платіжний шлюз RozetkaPay Enhanced (Банківська картка) з розширеними логами та діагностикою.
- Обробка callback-сповіщень RozetkaPay:
  - оновлення статусів замовлень;
  - обробка підтверджених, відхилених та скасованих платежів;
- Опційне автопідтвердження угоди після підписання клієнтом.
- Переопитування статусів через payment info (cron), якщо увімкнено відповідну опцію.
- Окрема адмін-сторінка «RozetkaPay Частинами» зі статистикою та списком замовлень.
- Адмін-сторінка «RozetkaPay: Доступні банки (PayParts)» зі списком доступних банків з API RozetkaPay.
- Журнали API-запитів та callback-ів через WooCommerce logger.
- Підтримка багатомовності (готовий до локалізації).

Плагін сумісний з WooCommerce HPOS (High-Performance Order Storage / custom order tables).

## Встановлення

1. **Завантажте** або клонуте цей репозиторій у директорію `wp-content/plugins`:
   ```sh
   git clone <repo-url> wp-content/plugins/rozetkapay-payparts
   ```
   або завантажте ZIP-архів плагіна і встановіть його через адмін-панель WordPress
(Плагіни > Додати новий > Завантажити плагін).
2. **Активуйте плагін через адмін-панель WordPress** (Плагіни > Встановлені плагіни).
3. **Переконайтеся, що WooCommerce активний** і ваш сайт відповідає мінімальним вимогам (PHP 7.4+, WooCommerce 5.0+).

---

## Налаштування

1. Перейдіть у `WooCommerce > Налаштування > Платежі`.
2. У списку способів оплати знайдіть:
   - **RozetkaPay Оплата частинами** (`rp_payparts`);
   - *(опційно)* **RozetkaPay Enhanced (Банківська картка)** (`rp_standard`), якщо ви хочете приймати також оплати банківською карткою через RozetkaPay.
3. Натисніть **«Керувати»** для **RozetkaPay Оплата частинами** та налаштуйте основні опції:
   - **Увімкнути/Вимкнути** — активувати або деактивувати спосіб оплати.
   - **Назва методу / Опис на сторінці оформлення** — тексти, які бачить користувач на сторінці checkout.
   - **API Користувач / API Пароль** — облікові дані для доступу до API RozetkaPay Payparts.
   - **Мінімальна / Максимальна сума замовлення** — обмеження сум для оплати частинами (`0` — використовувати ліміти API).
   - **Дозволені банки** — список slug-ів банків через кому, які можна використовувати для оплати частинами (залиште порожнім, щоб дозволити всі доступні банки).
   - **Дозволені періоди (місяці)** — наприклад: `3,6,12,24` — список кількостей місяців для оплати частинами.
   - **Стиль відображення** — спосіб показу варіантів розстрочки:
     - `cards` — картки;
     - `slider` — повзунок;
     - `list` — компактний список.
   - **Повідомлення в кошику / на сторінці оформлення** — кастомні тексти з підтримкою плейсхолдерів:
     - `{min}` — мінімальний щомісячний платіж;
     - `{max}` — максимальний щомісячний платіж;
     - `{cart_total}` — загальна сума кошика;
     - `{min_term}` — мінімальний термін розстрочки;
     - `{max_term}` — максимальний термін розстрочки.
   - **Префікс номера для Rozetka (`external_id`)** — використовується при формуванні `external_id` замовлення (наприклад, `roz1-12345`).
   - **Автопідтвердження платежу** — якщо ввімкнено, після підписання договору клієнтом угода може підтверджуватися автоматично.
   - **Переопитування статусів (polling)** — дозволяє періодично опитувати RozetkaPay через payment info для актуалізації статусів.
   - **Налагодження / журнали** — додаткові опції логування та діагностики інтеграції.
4. **RozetkaPay Enhanced (Банківська картка)** — API-логін/пароль, назву способу, опис та інші параметри платежів карткою.

## Використання

- **Оформлення із оплатою частинами:**
  1. Клієнт додає товари в кошик.
  2. На сторінках товарів і в кошику відображається віджет «Оплата частинами» з орієнтовним щомісячним платежем.
  3. На сторінці оформлення замовлення клієнт обирає спосіб оплати **«Оплата частинами RozetkaPay»**.
  4. Клієнт перенаправляється до RozetkaPay для вибору банку, строку та підтвердження угоди.
  5. Після успішної оплати RozetkaPay повертає клієнта на сайт, а плагін оновлює статус замовлення в WooCommerce.

- **Оплата карткою через RozetkaPay Enhanced:**  
  Якщо шлюз **RozetkaPay Enhanced (Банківська картка)** активний, клієнт може вибрати його як окремий спосіб оплати на checkout. Платіж проводиться через RozetkaPay, а статуси замовлень оновлюються callback-сповіщеннями.

- **Шорткод віджета розстрочки:**  
  Плагін надає шорткод для вставки віджета в контент:

  ```php
  [rp_payparts_widget price="1999" terms="3,6,12"]
  ```
  Якщо параметр price не вказано, плагін автоматично використовує ціну поточного товару.
- **Повернення коштів:**  
  Оформлюється зі сторінки замовлення в адмін-панелі WooCommerce.  
  Плагін відправляє запит повернення до RozetkaPay і оновлює статус замовлення відповідно до відповіді.

## Можливості для адміністратора

Плагін додає в адмін-панель WooCommerce:

- **Розділ «RozetkaPay Частинами»:**
  - **Огляд** — базова статистика оплат частинами та (за потреби) карткою;
  - **Замовлення** — список замовлень, проведених через RozetkaPay, з типом оплати, банком і статусом;
  - **Налаштування / Діагностика** — інформація про середовище (версії PHP/WP/WC), стан інтеграції, допоміжні інструменти.

- **Розділ «RozetkaPay: Доступні банки (PayParts)»:**
  - список доступних банків та тарифів, отриманих із API RozetkaPay;
  - індикація помилок підключення;
  - кнопка для оновлення даних.

Також доступні:

- Перевірка підключення до API (AJAX-тест);
- Очищення кешу технічних даних (банки, параметри).

## Журнали

Плагін веде журнали роботи інтеграції, включно з:

- створенням та оновленням платежів;
- callback-запитами від RozetkaPay;
- помилками API.

Журнали доступні через стандартну систему логів WooCommerce:

- `WooCommerce > Статус > Журнали`;
- джерело логів: `rp-payparts-api` (та пов’язані).

При увімкненому `WP_DEBUG_LOG` додаткова технічна інформація може записуватися у PHP-журнал (`error_log`).

## Переклад

- Файли перекладу знаходяться у директорії `languages/`.
- Доступні локалі:
  - `rp-payparts-uk_UA.*` — українська;
  - `rp-payparts-ru_RU.*` — російська.
- Базовий шаблон для локалізації: `rp-payparts.pot`.

Плагін готовий до локалізації через стандартні інструменти перекладу WordPress (Poedit, Loco Translate тощо).

## Розробка

Проєкт дотримується **WordPress Coding Standards**.

Для перевірки якості коду рекомендується:

- перевірка коду на відповідність стандартам WordPress:

  ```sh
  php ./vendor/bin/phpcs --warning-severity=0
  ```
  - автоматичне виправлення частини помилок:

  ```sh
  php ./vendor/bin/phpcbf
  ```
(Команди передбачають наявність встановленого phpcs/phpcbf через Composer або глобально.)
